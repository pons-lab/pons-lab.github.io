## 문제점 진단

### 심각 (리뉴얼의 핵심 근거)
1. **검색 노출 차단**: noindex 설정 — 구글에서 연구실이 검색되지 않음. 홍보 목적에 치명적.
2. **독립 도메인 부재**: sites.google.com/view/... URL은 기억·공유·명함 기재에 불리하고 신뢰감이 떨어짐.
3. **첫인상 약함**: 메인에 대표 비주얼·연구 하이라이트 없이 텍스트 위주. 강한 논문 실적이 메인에서 안 보임.

### 중간
4. **NEWS 비어 있음**: 메뉴는 있는데 콘텐츠 0건 — 방치된 인상을 줌. 갤러리도 4건 중 2건은 사진 없음.
5. **멤버 페이지 빈약**: 사진·관심분야 없음. 지원자가 랩 분위기를 가늠하기 어려움.
6. **주소 불일치**: PI 페이지(백운관 201호)와 Contact(산학관 204호)의 주소·전화번호가 서로 다름 — 정리 필요.
7. **Google Sites 표현 한계**: 디자인 자유도·타이포그래피·성능 제약, 학술 사이트 관례(논문 자동 목록, BibTeX 등) 구현 불가.

### 경미
8. 국문 콘텐츠 부재(국내 대학원생 지원자 고려 시 병기 검토 가치).
9. 논문 페이지에 DOI/PDF 링크, Google Scholar 연동 여부 확인 필요.
